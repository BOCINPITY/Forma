# 变更记录 / Changelog

## 1.0.0 — 2026-10-24

- 首个正式版，保留自带运行时、无需安装的使用方式。
- 移除调试符号与多余语言资源，提供高压缩 EXE 及兼容 ZIP，附 SHA-256。
- 压缩启动包沿用 Forma 图标；自动验证两种发布包的启动与图标渲染。

- First stable release, retaining the bundled runtime and portable experience.
- Removes debug symbols and surplus language resources; adds a compressed EXE alongside the compatible ZIP, with SHA-256 checksums.
- Branded launcher and automated startup/render checks for both release formats.

## 0.1.0-preview.9 — 2026-10-24

首个公开预发布版本。 / First public preview.

- 按图标形态调整大小、留白与 macOS 风格底板，保留原生尺寸细节。
- 浅 / 深桌面预览、实际像素对比、批量应用、自动备份与一键恢复。
- MIT 开源、中英文图文使用说明、GitHub Actions 构建和自动发布便携包。

- Shape-aware sizing, padding and macOS-inspired materials with native-frame rendering.
- Light/dark desktop previews, actual-pixel comparisons, batch apply, backups and one-step restore.
- MIT license, illustrated Chinese/English guides and automated Windows builds and releases.
