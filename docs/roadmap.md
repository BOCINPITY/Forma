# 开发路线图

本路线图按能力推进，不承诺未经评估的日期。当前为 `0.1.0-preview.6`。

## M0：项目基线

- [x] 独立目录、Git、文档与代码约定。
- [x] 项目本地 SDK、Release 构建、依赖锁文件和可复现脚本。
- [x] 自包含 Windows x64 便携版与 ZIP 打包脚本。

## M1：只读扫描

- [x] 系统 API 发现用户桌面及公共桌面。
- [x] 普通 .lnk 的解析、图标提取和不支持原因。
- [x] 图标网格、多选、只读预览、取消及空状态。
- [x] 中文 / 空格路径、失效链接、损坏链接验证。
- [ ] 实际 OneDrive / 企业重定向桌面的同步行为验证。

## M2：图标适配与预览

- [x] 精确固定 SkiaSharp 4.153.1，分析透明边界。
- [x] 可见大小、纯色 / 渐变 / 透明底板、留白与圆角。
- [x] 提供保留原画布及比例调整，处理已有底板的手动需求。
- [x] 16 / 20 / 24 / 32 / 40 / 48 / 64 / 80 / 96 / 128 / 192 / 256 ICO，Windows WIC 解码验证。
- [x] macOS 质感模式的保守底板识别、自动取色与连续圆角材质。
- [ ] 逐图标风格覆盖与更多异形底板的人工验收。

## M3：应用与恢复

- [x] 持久备份、写前批次记录、异常窗口恢复。
- [x] 修改图标引用，验证启动属性得到保留。
- [x] Shell 更新通知、逐项结果及冲突说明。
- [x] 验证部分失败、文件只读、重复应用、多批次逆序恢复和中途取消。
- [x] 应用后重启服务，历史可读取、原图可恢复。
- [ ] 用户真实桌面应用后的 Explorer 显示效果人工验收。

## M4：正式分发

- [x] 便携版、原创应用图标、使用说明及第三方许可。
- [x] 正常 / 空 / 失效目录的 WPF 截图验证。
- [ ] 多 DPI、长名称、大量图标、更多应用的视觉质量检查。
- [ ] 公共桌面真实权限、OneDrive 和长期使用验证。
- [ ] 安装 / 卸载、签名和自动更新方案。
- [ ] 决定项目许可证并完成正式发布流程。

完整主流程已可使用，下一阶段优先实际体验与兼容性打磨。当前不创建正式版本标签，不把开发预览称作正式发布版。

## 清晰度修订

- [x] 原生多帧提取、真实分辨率、预乘 Alpha 面积采样和统一圆角轮廓。
- [x] 实际尺寸预览、清晰优先、低清源提示及 DPI 几何回归。
- [ ] 真实多屏 DPI 切换和更多照片式图标人工验收。
