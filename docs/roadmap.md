# 开发路线图

本路线图按能力推进，不承诺未经评估的日期。

## M0：项目基线（当前）

- [x] 创建独立目录和项目文档。
- [x] 建立 WPF 启动骨架及开发检查脚本。
- [x] 初始化 Git 并保存基线提交。
- [ ] 安装或提供 .NET 10 SDK，完成首次构建和启动验证。

## M1：只读扫描

- [ ] 通过系统 API 发现用户桌面及公共桌面。
- [ ] 枚举普通 .lnk，解析图标和目标信息，标明不支持项。
- [ ] 显示图标网格、选择状态、失败原因及可取消进度。
- [ ] 使用中文、空格、重定向路径及失效链接验证。

## M2：图标适配与预览

- [ ] 接入固定版本 SkiaSharp，分析透明边界。
- [ ] 实现统一可见大小、底板、留白及手动调整。
- [ ] 支持已有底板的处理策略。
- [ ] 输出多尺寸 ICO，并验证预览与文件一致性。

## M3：应用与恢复

- [ ] 先完成持久化备份、批次记录和异常恢复策略。
- [ ] 修改选中的快捷方式图标引用，保留其他属性。
- [ ] 通知 Shell 更新并显示逐项结果。
- [ ] 验证部分失败、权限不足、重复应用、取消与恢复冲突。

## M4：可分发版本

- [ ] Windows 11 实机验证及多 DPI 检查。
- [ ] 明确缓存保留、卸载、打包和签名方案。
- [ ] 审查第三方依赖及素材许可，决定项目许可证。
- [ ] 完成使用说明、故障处理和版本发布记录。

下一步优先完成 M0 的 SDK 验证，再进入 M1；不会把窗口骨架当作可用适配器发布。
