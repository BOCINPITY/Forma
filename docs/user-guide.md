# Forma 使用说明

Forma 是 Windows 桌面图标适配工具，原名 IconAdapt。第一版处理普通 `.lnk` 应用快捷方式，可以预览、批量设置图标，并通过操作记录恢复。

## 启动

便携版请完整解压 `Forma-<版本>-win-x64` 文件夹，双击其中的 `Forma.exe`。不要只复制 EXE：同目录包含程序和图像处理所需的依赖。自包含版本不要求安装 .NET SDK。升级时先关闭旧窗口，再打开新版；默认仍沿用同一账户的原有备份和记录。更名后数据目录仍为 `%LOCALAPPDATA%\IconAdapt\`，不要手动改名或移动它。

当前是未签名的开发预览版本，尚无安装程序或自动更新功能。仅面向 Windows x64，优先验证 Windows 11。

## 适配图标

界面为单页工作台：左侧是图标网格，右侧是实际尺寸对比与适配设置，顶部提供“恢复默认图标”，底部显示状态和应用按钮。操作详情在当前页展开，不需要切换页面。窗口最小支持 960 × 680，缩小时基础设置与主操作仍保留在可见区域。

按钮、开关、选中态、预览切换与详情区带有短时过渡。Windows 设置中关闭动画效果后，界面会直接切换状态；动效不会改变导出图标或降低最终预览清晰度。

1. 打开程序后扫描桌面，或选择一个包含 `.lnk` 的文件夹。仅扫描该层，不递归处理子文件夹。
2. 选择要适配的快捷方式，查看原图与适配预览。
3. 点击“macOS 预设”使用自动配色、连续圆角与轻材质；也可选择渐变、纯色或无底板风格。用检查器的 32 / 48 / 64 / 96px 按钮比较实际输出，按需要调整图案比例和圆角。
4. 透明边界裁切可以让视觉大小更统一。对已有完整底板的图标，可以关闭裁切并调整比例。
5. 确认效果后应用选中项。程序先备份并保存记录，再修改快捷方式的图标引用。
6. 查看图标上的状态，点击底部提示或展开左下“操作详情”查看具体原因。部分失败时，成功项仍保留，可通过“恢复默认图标”统一还原。

“清晰优先”会去除透明留白，并将图案占比设为 80%；升级不会自动替换原有风格。实际尺寸预览直接读取导出文件内的对应帧。原图太小时会提示，放大不能补回原图没有的细节。使用底板时超出圆角轮廓的部分会被裁切，必要时降低图案比例。

“macOS 预设”将风格设为 macOS 质感，图案比例 80%、圆角 23%、去除透明留白。颜色行显示“跟随应用配色”，该模式自动从原图取色：识别出完整底板时保留它的颜色并填满新轮廓；透明图案使用轻微带色的浅底板。识别采用保守的图像规则，少数特殊图案可能仍需切回传统风格手动调整。它统一外轮廓与材质，不重画应用标志中的文字或细节。

扫描、选择和预览不会修改快捷方式；只有应用和恢复会写入快捷方式。图标刷新可能稍有延迟，可先等待或手动刷新桌面。

## 检查整组图标

在图标库勾选想比较的项目，然后切换“桌面预览”。可切换浅色 / 深色背景、原始 / 适配后，并使用 32 / 48 / 64 / 96px 检查整组效果。点击一个图标，右侧继续显示它的前后对比和画质信息；切换背景、视图或尺寸不会应用图标。

这里只显示已勾选项目；取消全部勾选后返回图标库重新选择。没有生成适配输出的项目会显示原图并标注“未生成，显示原图”，不能把它当作成功的适配结果。背景和位置是模拟的，不会读取真实壁纸或移动桌面图标。

## 恢复默认图标

点击顶部“恢复默认图标”并确认，程序自动还原所有由 Forma 适配过的快捷方式。同一个快捷方式连续多次适配，会自动逐层还原到首次适配前，无需选择记录。“默认”指 Forma 修改前的图标引用，包含你原先设置的自定义图标，不强行覆盖成软件内置图标。此按钮不会重置右侧风格设置。

恢复范围为当前数据目录中的全部适配记录，包括其他文件夹中的快捷方式，不受当前扫描目录或勾选范围限制。默认数据目录属于当前 Windows 账户；没有需要恢复的项目时按钮禁用。旧版备份可继续使用，底层记录用于安全恢复，不再展示为独立页面。

恢复前程序会检查文件是否已被外部修改。出现冲突时保留当前文件，该快捷方式的更早适配层也会停止恢复；其他项目继续处理。结果按快捷方式计数，只有全部适配层都还原才算成功。在“操作详情”查看失败原因；解决权限、占用或冲突后可再次点击恢复。中途停止或重启后也可继续。

## 文件保存在哪里

默认数据目录是 `%LOCALAPPDATA%\IconAdapt\`，其中包含生成的图标、快捷方式备份和操作记录。具体子目录见开发文档。

**使用图标期间请保留这个目录。** 桌面快捷方式会引用其中的 ICO 文件；关闭或移动程序文件夹不会主动还原图标。要移除工具及其数据，请先点击“恢复默认图标”，确认全部完成及桌面效果，再清理数据。

## 常见情况

- **没有找到快捷方式**：桌面可能只有文件夹或系统特殊图标，或者快捷方式位于其他目录，可选择文件夹扫描。
- **项目无法适配**：失效、损坏或特殊类型入口可能不支持，界面会说明原因。
- **权限不足**：公共桌面可能只有读取和执行权限。先关闭窗口，右键 `Forma.exe` 选择“以管理员身份运行”，确认 UAC，再重新扫描并仅重试失败项；不提升时只选择当前账户可写项。程序不会自动提权。若换了管理员账户，原账户的默认数据目录与历史不会自动共享。
- **图标尚未刷新**：Shell 通知不保证立即更新所有显示位置。当前版本不会自动重启 Explorer 或删除系统图标缓存。
- **任务栏没有一起变化**：当前只修改选中的快捷方式，不保证任务栏、开始菜单或正在运行的应用图标同步变化。

公共桌面拒绝访问及旧版属性保护误报的详细处理见 [应用失败排查](troubleshooting-apply.md)。

## 开发者测试启动

可指定自建快捷方式目录及独立数据目录，避免混入真实桌面操作记录：

```powershell
.\scripts\run.ps1 -ScanFolder 'E:\local\IconAdapt\.local\demo' -DataRoot 'E:\local\IconAdapt\.local\demo-data'
```

自动化验证使用项目 `.local` 下的测试目录，不会替换真实桌面图标。
