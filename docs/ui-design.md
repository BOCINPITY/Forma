# 界面设计

## preview.7：单页与直接恢复

移除顶部工作台 / 恢复记录导航及历史页，顶部只增加低强调的“恢复默认图标”。用户不选择批次，连续多次适配由程序自动还原。底部保留应用 / 停止，操作详情在左下展开并独立滚动，右侧设置保持原位。恢复语义、全量范围及冲突处理见 [使用说明](user-guide.md)。

## preview.6：材质与分组

采用 macOS 浅色桌面工具的层次：一体工具栏、雾灰画布、内缩的白色圆角图标面板、柔蓝预览区域和成组设置。分割主要由留白、表面明暗与轻微阴影完成。选中、滑块、开关和主操作统一为蓝色，基础文字沿用上一版的清晰字号。

面板材质由 WPF 渐变和阴影绘制，不读取或模糊用户桌面。Windows 11 使用 DWM 圆角提示，旧版 Windows 可忽略该提示；窗口保留标准最小化、最大化与关闭行为。

图标质感由独立的 macOS 材质模式实现，详细处理和边界见 [图标清晰度与材质](icon-quality.md)。

## preview.5：Forma

在 preview.4 的布局基础上统一产品名、代码绘制的标志与字体体系。正文和辅助信息提升可读性，统一中英混排、数字、字重和文字颜色；窗口标题及应用文件名改为 Forma。详细规范见 [品牌与字体](brand.md)。

## preview.4 的调整

桌面工具的主要内容是图标及其对比。旧布局的侧栏、大标题和大卡片占据了过多空间；在约 1046px 宽的窗口里只能看到两列图标，右侧设置需要滚动才能到达。

新版采用浅灰画布、白色面板、石墨色文字与主按钮，蓝色仅用于选中和焦点。顶部集中工作台 / 恢复记录导航，去掉侧栏和宣传标题。标题栏保留 Windows 的窗口操作习惯。

工作区使用紧凑图标网格，右侧检查器固定宽度。实际像素对比与基础设置保留在可见区域，补充诊断放入详情区。底部固定显示状态及应用 / 恢复按钮，长路径和完整诊断通过详情或工具提示查看。

## 图标和状态

- 网格显示 48 个物理像素；对比支持 32 / 48 / 64 / 96px，直接读取 ICO 内的对应帧，不通过放大图片填满卡片。
- 图标勾选表示将要应用的集合；当前焦点表示右侧正在查看的图标，两者独立。
- 成功与就绪使用中性色；原图尺寸限制属于画质提示；失败、冲突、待核对才使用问题提示。
- 保留错误原文与处理建议，简短状态不能替代诊断信息。

## 布局验收

最小窗口为 960 × 680，默认 1220 × 800。使用合成图标检查 960 × 680、1046 × 794 和 1280 × 820：基础设置、主操作、96px 对比不裁切；长标题省略；多图标可滚动；详情展开不挤走基础设置。单独检查恢复按钮启用 / 禁用、长结果滚动与空状态。
