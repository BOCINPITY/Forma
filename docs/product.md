# 产品范围

## 目标

让 Windows 桌面应用图标在视觉大小、留白和背景上形成一致风格，同时保留应用识别特征。初期面向 Windows 11，其他系统版本需单独验证后再声明支持。

## 第一版用户流程

1. 扫描当前用户桌面及公共桌面中的普通 `.lnk`，展示名称、原图标和处理状态。
2. 选择快捷方式，调整底板风格、背景色、图案大小和留白。
3. 本地生成预览，不修改桌面。
4. 用户点击应用后，先生成备份及持久化记录，再修改图标引用。
5. 显示每项结果，支持重试失败项及恢复已修改项。

## 视觉规则

- 依据透明通道分析实际图案边界；不能只按原始画布尺寸等比缩放。
- 对已有底板的图标提供保留原图和手动调整选项，避免重复套框。
- 默认保留标志及主色；macOS 质感自动取色，用户可切换传统底板模式手动选色。
- 预览与输出采用同一渲染管线，检查小尺寸下的识别度。
- 清晰度和识别度优先于形式统一；保留原生小尺寸版本，使用真实像素预览，避免以大幅预览代替小图质量验收。
- 规则处理先行，第一版不依赖模型服务或网络生成。

## 边界

- 特殊 Shell 入口、商店应用专用入口及无法解析的快捷方式应跳过并说明原因。
- 公共桌面项目可能不可写，应报告权限问题，不自动提权。
- 系统图标、任务栏、开始菜单、文件类型关联、文件夹及桌面布局不在第一版范围内。
- 不要求常驻后台；已生成的图标文件必须持久保留，以供 Shell 使用。

## 验收目标

- 选中项目均能看到原图与适配图的对比。
- 普通 `.lnk` 应用后仍保持原有启动目标、参数和工作目录。
- 应用失败或程序中断后，可以依据记录定位已修改项并恢复。
- 重复应用、分批恢复、源程序卸载、图标显示延迟都有明确结果或说明。
- 日志、缓存及备份保存在本机，不自动上传。
